뽀모도로 개인정보처리방침

시행일: 2026년 10월 29일

"뽀모도로"(이하 "앱")는 회원가입이나 로그인 없이 사용하며, 개발자는 이용자의 개인정보를 직접 수집하거나 보관하지 않습니다. 다만 앱에 포함된 광고(Google AdMob)를 통해 아래 3항의 정보가 Google 에 전송될 수 있습니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 수집하는 개인정보

개발자는 이름, 이메일, 전화번호 등 이용자를 식별할 수 있는 정보를 수집하지 않습니다. 회원가입이나 로그인 기능이 없습니다.

2. 기기에 저장되는 정보

앱이 동작하는 데 필요한 아래 정보는 이용자의 기기 안에만 저장되며, 외부 서버로 전송되지 않습니다.

  • 타이머 설정(집중·휴식 시간, 하루 목표, 자동 시작 여부 등)
  • 완료한 집중·휴식 세션의 종류, 길이, 종료 시각
  • 진행 중인 타이머의 상태

이 정보는 개발자를 포함해 누구에게도 전송되지 않습니다. 앱을 삭제하거나 기기 설정에서 앱 데이터를 지우면 모두 삭제됩니다.

3. 광고 (Google AdMob)

앱은 무료로 제공되며, 화면 아래에 Google AdMob 배너 광고를 표시합니다. 광고를 보여주고, 광고 성과를 측정하고, 부정 클릭을 막기 위해 Google Mobile Ads SDK 가 다음 정보를 자동으로 수집해 Google 에 전송합니다.

  • IP 주소 (대략적인 위치 추정에 쓰일 수 있음)
  • 광고 노출·클릭, 앱 실행 같은 앱 사용 기록
  • 앱과 SDK 의 성능·오류 등 진단 정보
  • 광고 ID(Android 광고 ID), 앱 세트 ID 등 기기 식별자

이 정보는 전송 중 암호화(TLS)되며, Google 의 정책에 따라 처리됩니다. 자세한 내용은 Google 파트너 사이트의 데이터 사용 방식과 Google 개인정보처리방침을 참고하세요.

맞춤 광고를 원하지 않으면 기기의 설정 → Google → 광고에서 광고 ID 를 삭제하거나 재설정할 수 있습니다. 유럽 등 동의가 필요한 지역에서는 앱을 처음 열 때 동의 여부를 묻고, 앱의 설정 → 광고 개인정보 옵션에서 언제든 바꿀 수 있습니다.

개발자는 위 정보를 직접 받거나 보관하지 않으며, 이 밖의 제3자에게 정보를 제공하지 않습니다.

4. 앱이 사용하는 권한

  • 알림: 남은 시간 표시와 세션 종료 알림을 보내기 위해 사용합니다.
  • 정확한 알람 예약: 앱이 닫혀 있어도 세션이 끝나는 시각에 맞춰 알림을 보내기 위해 사용합니다.
  • 인터넷, 광고 ID: 광고를 불러오고 표시하기 위해 광고 SDK 가 사용합니다.

5. 아동의 개인정보

앱은 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.
